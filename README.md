# ALIEN-RUS-FORK

Русскоязычный форк [ALIEN](https://github.com/chrxh/alien) — симулятора искусственной жизни, разработанного Christian Heinemann и участниками проекта.

В этом форке основной интерфейс и встроенная текстовая справка ALIEN переведены на русский язык.

## Состояние перевода

### Переведено

- Основной интерфейс программы: меню, настройки, инструменты, редактор генома, инспекторы, статистика, браузер, окна аккаунта и MCP.
- Встроенная текстовая справка F1: все 19 Markdown-файлов (18 глав).

### Не переведено

- Консольный режим и `alien-cli`.
- Часть сторонних элементов интерфейса и технических диагностических сообщений.
- Английские надписи на 25 схемах справки (текстовые пояснения к ним переведены).

Русский и английский языки доступны в настройках программы.

## Об ALIEN

**ALIEN (Artificial Life Environment)** — симулятор искусственной жизни, позволяющий создавать и исследовать виртуальные миры, населённые цифровыми организмами.

Организмы состоят из взаимодействующих клеток, могут двигаться, получать и расходовать энергию, размножаться, мутировать и конкурировать за ресурсы. Их поведение определяется клеточными функциями, нейронными сетями и генетической информацией.

Симулятор позволяет экспериментировать с условиями среды, наблюдать за эволюцией популяций, конструировать организмы и исследовать возникающие формы поведения.

Для физических расчётов используется GPU.

Подробное описание возможностей, иллюстрации и документация доступны в [оригинальном README ALIEN](README.upstream.md).

## Сборка на Windows

Для сборки необходимы:

- Visual Studio 2022 с поддержкой C++ и CMake.
- NVIDIA CUDA Toolkit и совместимый драйвер.
- Git.

Клонирование репозитория вместе с зависимостями:

```bash
git clone --recurse-submodules https://github.com/scvarr/ALIEN-RUS-FORK.git
cd ALIEN-RUS-FORK
```

Сборка:

```
.\build-windows-ninja.bat agent
```

Запуск:

```
cd build-agent\Release
.\alien.exe
```

Дополнительные сведения о сборке и других платформах содержатся в [документации оригинального проекта](README.upstream.md).
