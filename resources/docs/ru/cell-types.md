# Типы клеток

Эта глава подробно описывает каждый тип клетки: его действия, читаемые и записываемые каналы сигнала, свойства и влияющие на него параметры симуляции. Также рассматривается конструктор: это не самостоятельный тип клетки, а дополнительная функциональность, доступная почти любой клетке.

## Как работают типы клеток

Каждая клетка работает циклами по 6 шагов времени. В каждом цикле нейросеть клетки сначала вычисляет восемь каналов её сигнала. Затем тип клетки выполняет свою функцию. Он читает каналы сигнала как входы и может перезаписать некоторые каналы результатами. Соединённые клетки видят эти результаты в следующем цикле. Подробности этого процесса см. в главе [Нейросети и сигналы](neural-networks.md).

Для всех типов клеток действуют общие правила:

- Клетка активна только в состоянии **готовности**. Строящиеся клетки остаются неактивными до завершения организма или части тела.
- Многие типы клеток действуют только при **срабатывании**. Клетка срабатывает, когда модуль значения канала #0 не меньше **0.1**. Некоторые типы дополнительно различают положительные и отрицательные значения.
- Типы клеток, которым нужно направление, например сенсоры, мышцы и коммуникаторы, используют **переднее направление** организма. Оно задано в геноме и передаётся от головной клетки остальным. Такие функции работают только у клеток организма с головной клеткой.
- Значения каналов лежат в диапазоне от -2 до 2. Направления кодируются значением от -1 до 1, соответствующим углу от -180 до 180 градусов относительно переднего направления.
- Энергия, которую тип клетки расходует, например на атаку, не теряется. Она испускается в виде энергетических частиц.

## Базовая

Базовая клетка не имеет специальной функции. Выполняется только её нейросеть. Базовые клетки подходят для структуры тела, передачи сигналов и их обработки нейросетью.

![Базовая клетка передаёт сигнал соседа. Сенсор справа передаёт сигнал через базовую клетку мышце слева. Базовая клетка обрабатывает и передаёт сигналы; с нейросетью по умолчанию копирует сигнал соседа. Английский оригинал сохранён: проверенного редактируемого исходника нет.](../images/cell-base.png)

**Пример:** цепочка базовых клеток между сенсором и мышцами передаёт сигнал сенсора без изменений, поскольку нейросеть по умолчанию копирует сигнал. Базовая клетка с изменённой нейросетью может, например, инвертировать направление или объединять два сигнала.

## Накопитель

Накопитель запасает доступную энергию и возвращает её по запросу. Он служит энергетическим запасом организма.

![Накопитель переводит энергию в запас при положительном канале #0 и высвобождает её при отрицательном канале #0. Накопитель при положительном сигнале запасает избыток над нормальной энергией, при отрицательном высвобождает запас. Жёлтые стрелки показывают оба направления; прямоугольник — запасённая энергия накопителя, а не зарезервированная энергия конструктора. Английский оригинал сохранён: проверенного исходного макета нет.](../images/cell-depot.png)

### Сигналы

| Канал | Значение |
| --- | --- |
| #0 (вход) | Не меньше 0.1: запасать энергию. Не больше -0.1: высвобождать энергию. |

При запасании накопитель переносит до 2 единиц энергии за цикл из доступной энергии в запас, но только часть сверх нормальной энергии. При высвобождении он возвращает до 2 единиц за цикл. Запасённая энергия является частью организма: атакующие клетки могут её отбирать, а после высвобождения она питает остальные клетки через обычный поток энергии.

### Свойства

| Свойство | Значение |
| --- | --- |
| Предел запаса энергии | Максимальное количество доступной энергии, которое накопитель может запасти. В любом случае симуляция ограничивает запас значением 500. |
| Запасённая энергия | Текущий запас энергии (только при инспектировании). |

**Пример:** используйте вход телеметрии *Энергия* нейросети: запасайте энергию при высоком уровне энергии клетки и высвобождайте при низком.

## Сенсор

Сенсор сканирует окружение и сообщает о ближайшем совпадении с условиями поиска. Это глаз организма.

![Сенсор испускает лучи сканирования, находит ближайшую подходящую цель и сообщает её направление, массу и расстояние. Лучи обозначают поиск ближайшего подходящего объекта, пунктир — направление вперёд, угол — направление найденной цели, преграда — частицы, закрывающие обзор. Справа показаны обнаружение, направление, масса и расстояние; значения иллюстративны, не измерены для нарисованного организма. Английский оригинал сохранён без изменения лучей и чисел: исходного макета нет.](../images/cell-sensor.png)

### Сигналы

| Канал | Значение |
| --- | --- |
| #0 (вход) | Запускает сканирование, если **Автозапуск** выключен и модуль значения не меньше 0.1. Отрицательное значение включает слежение, см. ниже. |
| #0 (выход) | 1, если что-то найдено, иначе 0. |
| #1 (выход) | Направление найденного относительно переднего направления, от -1 до 1. |
| #2 (выход) | Масса найденного: плотность энергетических частиц или свободных клеток от 0 до 1, а для организмов — значение, растущее с их размером (0.5 для 30 клеток, 0.75 для 60 клеток, 1 для 120 клеток и более). |
| #3 (выход) | Расстояние до найденного: 1 означает совсем рядом, 0 — 256 единиц или дальше. |

Каналы от #1 до #3 записываются только при успешном поиске.

### Как работает сканирование

Сенсор посылает 64 луча сканирования во всех направлениях и сообщает о ближайшем совпадении. Частицы твёрдого вещества блокируют лучи, поэтому организмы не видят сквозь камни и стены. Соединения собственного организма рядом с сенсором также блокируют лучи. Поэтому сенсор в середине тела видит меньше, чем сенсор на краю.

Если канал #0 отрицателен и сенсор уже нашёл цель, он не сканирует всё вокруг, а следует за прежней целью в её окрестности. Это полезно для слежения за движущейся целью.

### Режимы

| Режим | Что обнаруживает |
| --- | --- |
| Поиск энергии | Скопления энергетических частиц с плотностью не ниже значения **Мин. плотность**. |
| Поиск частиц | Частицы твёрдого вещества. |
| Поиск свободных клеток | Скопления свободных клеток с плотностью не ниже значения **Мин. плотность**, при необходимости с ограничением по цветам. |
| Поиск организмов | Клетки других организмов, при необходимости с ограничением по размеру, цвету и происхождению. |

### Свойства

| Свойство | Значение |
| --- | --- |
| Автозапуск | Сканирование в каждом цикле. Иначе его запускает канал #0. |
| Метки для атакующих | Атакующие клетки того же организма могут атаковать организмы, обнаруженные этим сенсором в режиме *Поиск организмов*. Это найденная цель и до 3 других подходящих организмов рядом с ней. Учитывается только сканирование текущего цикла. |
| Мин. расстояние, Макс. расстояние | Обнаруживаются только цели между этими расстояниями. |
| Мин. плотность | Для энергии и свободных клеток: требуемая плотность от 0 до 1. |
| Фильтр цветов | Обнаруживаются только объекты одного из выбранных цветов. |
| Мин. клеток организма, Макс. клеток организма | Для организмов: ограничения числа клеток целевого организма. |
| Происхождение | Для организмов: только родственные, только неродственные либо без ограничения. |

**Параметр:** *Тип клетки: Сенсор > Радиус сканирования* ограничивает дальность всех сенсоров (по умолчанию 255).

**Пример:** сенсор в последнем узле гена и мышцы перед ним в режиме *Прямое движение* создают организм, движущийся к обнаруженному сенсором. Мышцы читают признак обнаружения из канала #0 как силу, а направление — из канала #1. Пошаговое построение этой конструкции описано в главе [Ваш первый организм](first-creature.md).

## Генератор

Генератор создаёт периодический сигнал в канале #0, подобный сердцебиению или часам.

![Генератор выдаёт прямоугольный или пилообразный сигнал. Генератор создаёт периодический сигнал, а не энергию. Слева прямоугольный, справа пилообразный сигнал; отмечены минимум, максимум и период. Дискретная фаза упрощена. Английский оригинал сохранён: проверенного исходного макета нет.](../images/cell-generator.png)

### Сигналы

| Канал | Значение |
| --- | --- |
| #0 (выход) | Созданное значение. |

### Свойства

| Свойство | Значение |
| --- | --- |
| Режим | *Прямоугольный сигнал*: максимальное значение в первой половине периода, минимальное — во второй. *Пилообразный сигнал*: линейно возрастает от минимального до максимального значения за период. |
| Период | Длительность одного периода в шагах времени. Поскольку клетки работают каждые 6 шагов времени, лучше выбирать кратные 6 значения. |
| Мин. значение, Макс. значение | Два уровня сигнала, от -2 до 2. |
| Сдвиг по времени | Сдвигает фазу на это число шагов времени. |
| Сложение с сигналом | Прибавляет значение к каналу #0 вместо замены. |

**Пример:** прямоугольный сигнал, поданный в клетку памяти в режиме *Запись сигналов*, запускает запись через равные промежутки. При одинаковых минимальном и максимальном значениях генератор создаёт постоянный сигнал — простой способ постоянно активировать мышцы.

## Атакующая

Атакующая клетка отбирает энергию у свободных клеток или клеток других организмов. Это рот или оружие организма.

![Атакующая клетка отбирает энергию у цели, помеченной сенсором того же организма. Конвертер превращает добычу в доступную энергию. Сенсор обнаруживает и помечает цель; оранжевая стрелка показывает отбор энергии у чужого организма, затем сырая энергия идёт в соседний конвертер. Нижние подписи тесно расположены. Английский оригинал сохранён: без исходного макета нельзя достоверно переразместить перекрывающиеся подписи и стрелки.](../images/cell-attacker.png)

### Сигналы

| Канал | Значение |
| --- | --- |
| #0 (вход) | Запускает атаку, если модуль значения не меньше 0.1. |
| #2 (выход) | Успех: отобранная энергия, делённая на 10, от 0 до 1. |

### Как работают атаки

Атака поражает все подходящие цели в пределах **радиуса атаки**, не скрытые клетками собственного организма. Отобранная энергия добавляется к **сырой энергии** атакующей клетки. Сырую энергию нельзя использовать напрямую. Она поступает в непосредственно соединённые **конвертеры**, которые её преобразуют. Поэтому атакующая клетка без соседнего конвертера бесполезна. Следующая атака происходит только после снижения сырой энергии ниже 2.

Количество энергии зависит от нескольких факторов:

- **Сила атаки** задаёт долю энергии цели, отбираемую за шаг времени.
- **Цветовая матрица пищевой цепи** масштабирует количество в зависимости от цветов атакующей клетки и цели.
- **Защитники** у цели уменьшают количество.
- **Защита своего происхождения** ослабляет атаки на родственные организмы, а **Защита по размеру** — атаки на более крупные организмы.

Каждая попытка атаки требует **расхода энергии**, испускаемой в виде энергетических частиц. Атакующая клетка не атакует, если её доступная энергия при этом опустится ниже минимальной.

### Режимы

| Режим | Цели |
| --- | --- |
| Свободные клетки | Свободные клетки, при необходимости с ограничением по цветам. |
| Организмы | Клетки других организмов. Атакуются только организмы, которые сенсор того же организма обнаружил и пометил в текущем цикле; см. свойство сенсора **Метки для атакующих**. Собственное потомство никогда не атакуется. |

**Параметры:** группа *Тип клетки: Атакующая*: **Расход энергии**, **Цветовая матрица пищевой цепи**, **Сила атаки**, **Защита своего происхождения**, **Защита по размеру** и **Радиус атаки** (по умолчанию 2).

**Пример:** хищнику нужны сенсор в режиме *Поиск организмов* с настройкой **Метки для атакующих**, атакующая клетка и соединённый с ней конвертер. Сенсор должен сканировать в том же цикле, в котором срабатывает атакующая клетка, например с помощью **Автозапуска**. Сигнал сенсора может запускать атакующую клетку через канал #0.

## Инжектор

Инжектор заражает клетку другого организма собственным геномом, подобно вирусу. Заражённая клетка начинает строить то, что указывает инжектор.

![Инжектор захватывает чужую клетку с конструктором, которая затем строит ген из генома инжектора. Инжектор передаёт геном чужой клетке с конструктором, который затем строит по внедрённому геному. Правая поясняющая надпись обрезана в самом английском оригинале. Её точное окончание не восстановлено; смысл пояснён по коду, изображение сохранено без выдуманного продолжения и без исходного макета.](../images/cell-injector.png)

### Сигналы

| Канал | Значение |
| --- | --- |
| #0 (вход) | Запускает инъекцию, если модуль значения не меньше 0.1. |
| #1 (выход) | 1 при успешной инъекции, иначе 0. |

### Как работает инъекция

Инжектор ищет в пределах **радиуса инъекции** клетку другого организма с конструктором, не статичную и без свойства генома **Защита от инъекций**. Целевая клетка захватывается: получает копию генома инжектора, её конструктор настраивается на ген, заданный свойством **Индекс гена** инжектора, и начинает заново.

Инъекция требует **расхода энергии** инжектора, по умолчанию 250, которая испускается в виде энергетических частиц. Каждый защитник в режиме *Защита от инъекций*, соединённый с целью, увеличивает стоимость. Инжектор действует только если после оплаты его доступная энергия остаётся выше минимальной.

### Свойства

| Свойство | Значение |
| --- | --- |
| Индекс гена | Ген из генома инжектора, который строит заражённая клетка. |

**Параметры:** группа *Тип клетки: Инжектор*: **Расход энергии** и **Радиус инъекции** (по умолчанию 3).

## Мышца

Мышца двигает организм. Она может изгибать сочленения, растягивать соединения или непосредственно ускорять себя.

![Три способа движения: изгиб сочленения, изменение длины соединения и прямой толчок клетки. Показаны три механических семейства: изгиб меняет угол у опоры, ползание — длину соединения, прямое движение ускоряет клетку. Это не полный перечень режимов управления. Английский оригинал сохранён: проверенного исходного макета нет.](../images/cell-muscle.png)

### Сигналы

| Канал | Значение |
| --- | --- |
| #0 (вход) | Активация: сила и, в управляемых режимах, направление действия. Значения ограничиваются диапазоном от -1 до 1. |
| #1 (вход) | Направление для режимов *Автоизгиб*, *Изгиб по углу* и *Прямое движение*, относительно переднего направления. |

### Режимы

| Режим | Функция |
| --- | --- |
| Автоизгиб | Самостоятельно изгибает сочленение туда и обратно между пределами угла. Канал #0 задаёт силу. Канал #1 задаёт желаемое направление движения. Мышцы, которые толкали бы в противоположную сторону, ослабляют или прекращают работу, позволяя организму поворачивать. |
| Управляемый изгиб | Сочленение изгибается в направлении, заданном знаком канала #0. |
| Изгиб по углу | Изгибает в направлении канала #1 и вместе с этим поворачивает переднее направление клетки. |
| Автоползание | Самостоятельно изменяет длину соединения туда и обратно. Канал #0 задаёт силу. |
| Управляемое ползание | Длина соединения меняется в направлении, заданном знаком канала #0. |
| Прямое движение | Непосредственно ускоряет клетку в направлении канала #1 с силой, заданной каналом #0. |

### Подробно об изгибе и ползании

Изгибающая мышца действует на сочленение у клетки, с которой связана первым соединением, — **опоры**. Она меняет угол между собой и следующим соединением опоры. Ползающая мышца меняет длину своего первого соединения. Изгибающие и ползающие мышцы должны иметь одно или два соединения; при изгибе два соседа не должны быть соединены друг с другом.

Тяга возникает из-за асимметрии ходов. **Баланс ходов вперёд/назад** распределяет скорость между прямым и обратным ходом, причём более быстрый ход создаёт большую тягу. При 0.5 оба хода компенсируют друг друга. **Макс. отклонение угла** и **Макс. изменение длины** ограничивают диапазон движения.

> **Совет:** изгибающим мышцам в автоматическом режиме нужен положительный сигнал в канале #0, например постоянный сигнал нейрона со смещением или генератора с равными минимумом и максимумом. Прямоугольный сигнал, чередующий положительные и отрицательные значения, так часто разворачивает ход, что организм почти не движется. Проще всего управлять режимом *Прямое движение*.

### Свойства

| Свойство | Значение |
| --- | --- |
| Режим | Один из шести режимов выше. |
| Макс. отклонение угла | Для изгиба: максимальное отклонение от исходного угла как доля доступного диапазона. |
| Баланс ходов вперёд/назад | Для автоматических и управляемых режимов: распределение скорости между двумя ходами. |
| Баланс притяжения/отталкивания | Для изгиба по углу: распределение скорости между двумя направлениями изгиба. |
| Макс. изменение длины | Для ползания: максимальное изменение длины соединения относительно исходной. |

**Параметры:** группа *Тип клетки: Мышца*: **Расход энергии**, **Ускорение движения** (прямое движение), **Ускорение ползания** и **Ускорение изгиба**.

## Защитник

Защитник оберегает организм. Он сам не совершает действий, но делает атаки или инъекции против окружающих клеток менее успешными.

![Защитник ослабляет атаки против себя и соседей. Защитник ослабляет атаку на цель: деление на сумму единицы и силы защиты применяется для каждого защитника. Схема относится к защите от атак, не от инъекций. Подписи у атакующей клетки скучены. Английский оригинал сохранён: без исходного макета нельзя гарантировать точное переразмещение текста.](../images/cell-defender.png)

### Режимы

| Режим | Эффект |
| --- | --- |
| Защита от атак | Если атакуемая клетка является таким защитником или непосредственно соединена с такими защитниками, отбираемая энергия делится на (1 + **Сила защиты от атак**) для каждого из них. |
| Защита от инъекций | Если цель инжектора непосредственно соединена с такими защитниками, расход энергии на инъекцию увеличивается на **Силу защиты от инъекций** для каждого из них. |

**Параметры:** группа *Тип клетки: Защитник*: **Сила защиты от атак** и **Сила защиты от инъекций**, оба по умолчанию 0.5.

## Соединитель

Соединитель создаёт соединения с другими объектами или удаляет их. Организмы могут использовать его, чтобы держаться за камни, хватать добычу или присоединяться к другим организмам.

![Соединитель соединяется с ближайшим подходящим объектом или разрывает все чужие соединения. Положительный сигнал создаёт связь с ближайшей подходящей целью, отрицательный разрывает связи с внешними объектами; связи своего организма сохраняются. Справа показана сеть частиц. Английский оригинал сохранён: проверенного исходного макета нет.](../images/cell-reconnector.png)

### Сигналы

| Канал | Значение |
| --- | --- |
| #0 (вход) | Не меньше 0.1: соединиться с ближайшим подходящим объектом. Не больше -0.1: удалить все соединения с объектами, не принадлежащими собственному организму. |
| #2 (выход) | 1, если соединение создано или удалено, иначе 0. |

### Режимы

| Режим | С чем соединяется |
| --- | --- |
| Частицы | Частицы твёрдого вещества. |
| Свободные клетки | Свободные клетки, при необходимости с ограничением по цветам. |
| Организмы | Клетки других организмов, при необходимости с ограничением по размеру, цвету и происхождению. |

Объект может иметь не более шести соединений, поэтому соединитель соединяется только при наличии свободного места с обеих сторон.

**Параметр:** *Тип клетки: Соединитель > Радиус соединения* (по умолчанию 2).

## Детонатор

Детонатор взрывается после обратного отсчёта и отталкивает всё вокруг.

![После обратного отсчёта детонатор взрывается, и распространяется ударная волна. Отсчёт приводит к взрыву и направленной наружу ударной волне. Радиусы нарисованы условно; момент срабатывания и задержка цепной активации упрощены. Английский оригинал сохранён: проверенного исходного макета нет, числовые подписи не исправлялись.](../images/cell-detonator.png)

### Сигналы

| Канал | Значение |
| --- | --- |
| #0 (вход) | Запускает обратный отсчёт, если модуль значения не меньше 0.1. |

### Как работает взрыв

После запуска детонатор отсчитывает один шаг за цикл. На нуле он взрывается: все объекты в пределах **радиуса взрыва** отталкиваются тем сильнее, чем они ближе. Другие детонаторы в этом радиусе тоже взрываются с **вероятностью цепного взрыва**. Затем ударная волна распространяется наружу до восьми радиусов взрыва. Статичные объекты не затрагиваются. Взорвавшийся детонатор остаётся неактивным.

### Свойства

| Свойство | Значение |
| --- | --- |
| Обратный отсчёт | Число циклов между запуском и взрывом. Один цикл состоит из 6 шагов времени. |
| Состояние | *Готов*, *Активирован* или *Взорвался* (только при инспектировании). |

**Параметры:** группа *Тип клетки: Детонатор*: **Радиус взрыва** (по умолчанию 10) и **Вероятность цепного взрыва** (по умолчанию 0.2).

## Конвертер

Конвертер превращает сырую энергию в доступную. Это желудок организма.

![Сырая энергия поступает от собирающих клеток в конвертер, который превращает её в доступную энергию. Сырая энергия идёт от атакующей клетки в непосредственно соединённый конвертер; доступная энергия далее распределяется по организму к базовой клетке и мышце. Английский оригинал сохранён: проверенного исходного макета нет.](../images/cell-digestor.png)

### Как работает преобразование

Клетки получают сырую энергию при поглощении энергетических частиц и атаках. Сырая энергия поступает от любой клетки в непосредственно соединённые конвертеры, а те передают её другим соединённым конвертерам. В каждом цикле каждый конвертер превращает часть сырой энергии в доступную, которая затем распространяется по организму обычным потоком энергии.

Два свойства конвертера взаимодополняют друг друга: высокая **проводимость энергии** означает, что он передаёт больше сырой энергии другим конвертерам и меньше преобразует сам. Высокое **преобразование энергии** означает обратное.

### Свойства

| Свойство | Значение |
| --- | --- |
| Проводимость энергии | Сколько сырой энергии клетка принимает и передаёт. Масштабируется параметром **Максимальная проводимость сырой энергии**. |
| Преобразование энергии | Сколько сырой энергии клетка преобразует за шаг времени. Масштабируется параметром **Максимальное преобразование сырой энергии**. |

**Параметры:** группа *Тип клетки: Конвертер*: **Максимальная проводимость сырой энергии** и **Максимальное преобразование сырой энергии**.

**Пример:** каждой атакующей клетке нужен непосредственно соседствующий конвертер. Растительноподобные организмы, питающиеся энергетическими частицами, лучше растут, когда большинство их клеток — конвертеры.

## Память

Клетка памяти сохраняет сигналы во времени. Она может задерживать, записывать, хранить и сглаживать сигналы, обеспечивая организму кратковременную память.

![Четыре режима клетки памяти. Слева направо: Задержка сигнала, Запись сигналов, Хранилище сигналов, Сглаживание сигнала. Обозначения знака в рисунке упрощены: начало записи требует сигнала строго выше одной десятой, воспроизведения — строго ниже минус одной десятой. Последний график означает взвешенное экспоненциальное сглаживание, а не среднее по окну: новое значение равно сумме предыдущего с весом «один минус вес сигнала» и текущего с весом сигнала. Английский оригинал сохранён: буквальная замена подписей закрепила бы спорное упрощение; исходного макета нет.](../images/cell-memory.png)

### Режимы

| Режим | Функция |
| --- | --- |
| Задержка сигнала | Снова выдаёт сигнал через фиксированное число циклов. |
| Запись сигналов | Положительный канал #0 (не меньше 0.1) записывает последующие сигналы в буфер, по одной записи за цикл, до заполнения. Отрицательный канал #0 (не больше -0.1) воспроизводит запись, по одной записи за цикл. |
| Хранилище сигналов | Модуль канала #0 выбирает запись буфера: 0 — первую, 1 — последнюю. Значение 0 или больше читает запись, отрицательное — перезаписывает её текущим сигналом. |
| Сглаживание сигнала | Выдаёт скользящее среднее сигнала. |

### Свойства

| Свойство | Значение |
| --- | --- |
| Задержка | Для задержки сигнала: число циклов, не более 32. |
| Только чтение | Для записи и хранилища: клетка только читает буфер и никогда его не перезаписывает. Запись в режиме только чтения воспроизводится, когда модуль канала #0 не меньше 0.1. |
| Вес нового сигнала | Для сглаживания: вес текущего сигнала в среднем. При 0 сохранённое значение заморожено, при 1 сглаживания нет. |
| Маска каналов | Выбирает каналы, заменяемые сохранёнными значениями. Остальные каналы проходят без изменений. |
| Буфер сигналов | Открывает редактор сохранённых записей, позволяя заранее задать последовательность для записи в режиме только чтения. Буфер вмещает до 32 записей. |

**Пример:** запись в режиме только чтения с заранее заданной последовательностью направлений, запускаемая генератором, позволяет организму выполнять фиксированный танец или рисунок плавания.

## Коммуникатор

Коммуникатор обменивается сигналами между разными организмами. Он позволяет создавать стаи, предупреждения и сотрудничество.

![Отправитель передаёт сигнал получателям других организмов в пределах радиуса. Передатчик посылает все сигнальные каналы приёмнику другого организма. Направление пересчитывается в систему приёмника с сохранением абсолютного направления. Пунктирный круг условно показывает дальность; фильтры и односторонний режим здесь не показаны. Английский оригинал сохранён: проверенного исходного макета нет.](../images/cell-communicator.png)

### Сигналы

| Канал | Значение |
| --- | --- |
| #0 (вход, отправитель) | Запускает передачу, если модуль значения не меньше 0.1. |
| все (отправитель) | Передаются все восемь каналов отправителя. |
| #1 | Интерпретируется как направление. Преобразуется в систему отсчёта получателя, сохраняя то же абсолютное направление. |
| все (выход, получатель) | Получатель перенимает каналы отправителя. Его соседи читают их в следующем цикле. |

Связь происходит только между разными организмами, и обеим сторонам нужно действительное переднее направление.

### Режимы

| Режим | Свойства |
| --- | --- |
| Передача | **Радиус**: расстояние до получателей, не более 20. **В одну сторону**: передача только получателям со стороны, противоположной направлению, закодированному в канале #1. |
| Приём | **Фильтр цветов** и **Происхождение** выбирают допустимых отправителей. |

## Донор

Клетка-донор служит временным заполнителем. Она растворяется сразу после завершения сети клеток, которой принадлежит, и передаёт энергию соседям.

![Доноры служат временным каркасом и исчезают после построения. Доноры — временный каркас: после построения они передают энергию соседям и исчезают, оставляя конечную структуру. Это не уничтожение энергии. Английский оригинал сохранён: проверенного исходного макета нет.](../images/cell-void.png)

Доноры полезны для форм, которые нельзя построить напрямую. Генераторы форм строят клетки по фиксированному шаблону, а узлы-доноры резервируют позиции, которые затем освобождаются, например для создания промежутков, отверстий или отдельных частей. Первый и последний узлы гена не могут быть донорами, а клетки-доноры не могут иметь конструктор.

## Конструктор

Конструктор строит новые клетки по гену генома. Это не тип клетки, а дополнительная функциональность, которую может иметь любая клетка, кроме донора. В редакторе генома она включается выбором гена для свойства **Построение**. Благодаря конструкторам организмы растут и размножаются.

![Конструктор строит клетки гена одну за другой. Первый узел оказывается дальше всего. Новая клетка вставляется у конструктора, построенная цепочка отодвигается; начальный узел оказывается дальше всего от конструктора. Конструктор — дополнительная функция клетки. Английские подписи сохранены: проверенного исходного макета нет, перерисовка могла бы изменить порядок и стрелки.](../images/cell-constructor.png)

### Сигналы

| Канал | Значение |
| --- | --- |
| #0 (вход) | Запускает построение следующей клетки, если интервал автозапуска не задан и модуль значения не меньше 0.1. |
| #4 (выход) | 1, если в этом цикле построена клетка, 0, если попытка не удалась. |

### Как работает построение

При запуске конструктор строит следующую клетку своего гена. Каждая новая клетка стоит **нормальную энергию** клетки, по умолчанию 100. Конструктор сначала платит зарезервированной энергией, затем собственной доступной энергией, но сам никогда не опускается ниже нормальной энергии. Если энергии недостаточно и доступен внешний резервуар, он запрашивает энергию оттуда; см. [Энергия](energy.md#the-external-energy-pool).

Новые клетки вставляются между конструктором и ранее построенной клеткой. Поэтому первый узел гена оказывается дальше всего от конструктора, а последний — рядом с ним. Все клетки постройки остаются неактивными до построения последней. Если включено **Отделение**, завершённые клетки отсоединяются и образуют новый организм.

### Свойства

| Свойство | Значение |
| --- | --- |
| Интервал автозапуска | Конструктор запускает себя каждые n шагов времени. Без значения его запускает канал #0. |
| Угол построения | Направление первой новой клетки относительно середины наибольшего промежутка между существующими соединениями клетки с конструктором. |
| Обеспечение энергией | *Только создаваемые клетки*: конструктор оплачивает каждую новую клетку. *Включая последующие клетки*: также оплачивает зарезервированную энергию конструкторов в новых клетках, чтобы они могли строить свои гены без дополнительной энергии. *Free*: без затрат энергии. Нельзя задать в геноме. Используется семенами, созданными с энергией, и после первого потомка переключается на *Только создаваемые клетки*. |
| Отделение | Завершённая постройка отсоединяется и становится новым организмом. |
| Число ветвей | Сколько копий гена строится рядом друг с другом вокруг конструктора (без отделения). |
| Повторения | Сколько раз ген строится последовательно, причём каждая копия присоединяется к предыдущей. Может быть бесконечным. |
| Индекс гена | Ген, который строится. |

**Параметры:** группа *Строительство клеток* с параметром **Расстояние проверки соединений**, откладывающим построение, если новое соединение пересекало бы существующие соединения поблизости, и группа *Управляемая подача энергии* для внешней энергии. Глава [Геномы и построение](genomes.md) объясняет взаимодействие конструкторов, генов и форм.
