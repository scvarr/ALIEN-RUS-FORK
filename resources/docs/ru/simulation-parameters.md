# Параметры симуляции

Параметры симуляции — законы природы мира: как движется вещество, сколько энергии нужно клеткам, насколько сильны атаки и многое другое. Они сохраняются вместе с каждой симуляцией. Эта глава объясняет окно параметров, слои и источники излучения и перечисляет все параметры со значениями по умолчанию.

## Окно параметров

Откройте окно командой **Окна > Параметры симуляции** (Alt+4).

- **Обзор** вверху перечисляет базовые параметры, все слои и источники излучения. Выберите запись, чтобы показать её параметры ниже.
- Панель инструментов загружает, сохраняет, копирует и вставляет наборы параметров, добавляет слои и источники излучения, клонирует, удаляет и меняет их порядок. **Открыть в отдельном окне** показывает слой или источник в отдельном окне.
- **Поле фильтра** показывает только параметры, имена которых содержат заданный текст.
- У каждого изменённого параметра есть кнопка возврата к **опорному значению** — значению на момент загрузки симуляции. **Вставить опорные параметры** задаёт новые опорные значения из буфера обмена, что полезно для сравнения двух наборов параметров.
- **Экспертные настройки** содержат группы, выключенные по умолчанию, например правила переходов цветов.
- Наведите указатель на параметр, чтобы прочитать подсказку.

Наборы параметров можно сохранять в файлы *.settings.json* и загружать в другие симуляции.

## Значения по цветам

Многие параметры задаются отдельно для каждого из десяти цветов настройки. Они показывают ряд значений, по одному на цвет. Это позволяет создавать миры, где, например, зелёные клетки долго живут, а красные сильно атакуют. Для цветовой матрицы пищевой цепи и матрицы переходов настройки задаётся целая таблица соответствий цветов.

## Слои и источники излучения

**Базовые параметры** действуют во всём мире. **Слои** переопределяют часть из них в отдельной области:

- У слоя есть **положение**, необязательная **скорость** перемещения по миру и **форма**: круг с радиусом полного воздействия или прямоугольник с размером полного воздействия. Вокруг этой области действие ослабевает на **ширине зоны затухания**.
- **Непрозрачность** смешивает слой с тем, что находится ниже. При 1 слой полностью заменяет значения в области полного воздействия, при 0 не действует.
- В слое параметр переопределяется только при включённом переопределении. Все остальные параметры сохраняют базовое значение.
- При перекрытии слоёв приоритет имеет более поздний слой в списке. Меняйте порядок кнопками со стрелками.
- Слой может создавать **силовое поле**, действующее на все объекты и энергетические частицы внутри него; см. группу *Силовое поле*.
- Слой может окрашивать фон своим цветом и отображать силовое поле, что часто используется для искусства.

Слои могут переопределять следующие параметры: цвет фона, трение, жёсткость связанных частиц, максимальную силу, порог скорости соединения, коэффициент поглощения, интенсивность излучения типа I, минимальную энергию, вероятность распада умирающих клеток, расход энергии атакующей клетки, цветовую матрицу пищевой цепи и защиту по размеру, правила переходов цветов и **Отключить источники излучения**, выключающий все источники внутри слоя.

**Источники излучения** — места появления энергетических частиц. У них есть положение, скорость, круглая или прямоугольная форма, доля и необязательный угол излучения. При аппаратной трассировке лучей они также светят с собственными яркостью, цветом и дальностью. См. [Энергия](energy.md#radiation-sources).

> **Примечание:** параметра гравитации нет. Гравитация, ветер и течения создаются слоями с линейным силовым полем. Слой на весь мир со слабой силой вниз действует как гравитация.

## Метамутации

Метамутации меняют вероятности мутаций, хранящиеся в геномах с включённой настройкой **Применять метамутации**. Каждый параметр — стандартное отклонение случайного изменения вероятности одного вида мутаций на потомка. По умолчанию все равны 0, то есть вероятности мутаций остаются постоянными.

| Группа | Параметры |
| --- | --- |
| Метамутации: свойства | Нейроны: сигма, Соединения: сигма, Свойства типов клеток: сигма, Конструктор: сигма, Геометрия: сигма |
| Метамутации: идентичность клетки | Тип клетки: сигма, Режим типа клетки: сигма, Донор: сигма, Настройка: сигма, Матрица переходов настройки |
| Метамутации: структура гена | Добавление узла: сигма, Удаление узла: сигма, Расширение гена: сигма, Укорочение гена: сигма, Копирование участка узлов: сигма, Перемещение участка узлов: сигма |
| Метамутации: структура генома | Добавление гена: сигма, Дублирование гена: сигма, Удаление гена: сигма, Перестановка генов: сигма |

## Тип клетки: Сенсор, Соединитель и Детонатор

| Параметр | По умолчанию | Значение |
| --- | --- | --- |
| Сенсор: Радиус сканирования | 255 | Верхний предел дальности сканирования сенсоров. По цветам. |
| Соединитель: Радиус соединения | 2 | Максимальное расстояние, на котором соединители создают соединения. По цветам. |
| Детонатор: Радиус взрыва | 10 | Радиус взрыва. Ударная волна достигает расстояния в восемь раз больше. По цветам. |
| Детонатор: Вероятность цепного взрыва | 0.2 | Вероятность того, что взрыв запустит другие детонаторы в радиусе взрыва. По цветам. |

## Правила переходов цветов объектов

Эта экспертная настройка по умолчанию выключена. При включении каждому цвету можно назначить следующий цвет и длительность. Клетки и свободные клетки, сохранявшие цвет в течение этой длительности, переходят к следующему цвету, а их возраст сбрасывается. Возможны цепочки и циклы цветов. Правила также задаются по слоям.
