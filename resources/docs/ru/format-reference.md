# Справочник формата

Эта глава показывает элементы Markdown, поддерживаемые просмотрщиком документации. Каждая глава — файл `.md` в `resources/docs`. Файл `contents.md` задаёт оглавление. Каждый его заголовок начинает часть, а каждый пункт списка со ссылкой становится главой, название которой берётся из текста ссылки.

## Текст

Абзацы переносятся автоматически. Стили внутри строки: **полужирный**, *курсив* и `код внутри строки`. Курсивный текст показывается более ярким цветом, поскольку курсивного шрифта нет.
Строка, заканчивающаяся обратной косой чертой\
принудительно переносится.

## Списки

- Пункт маркированного списка
- Ещё один пункт
  - Вложенный пункт
  - Ещё один вложенный пункт
- Снова первый уровень

1. Первый шаг
2. Второй шаг

   Пункт списка может содержать дополнительные абзацы и блоки кода. Они имеют такой же отступ, как текст пункта.

   ```
   Код внутри пункта списка
   ```

3. Третий шаг

## Таблицы

Столбцы выравниваются по левому краю. Столбцы с выравниванием по правому краю задаются как `---:` и предназначены для чисел.

| Параметр | Единица | Значение |
| --- | --- | ---: |
| Размер шага времени | | 1.0 |
| Радиус | px | 64 |
| Энергия | | 1,500 |

## Изображения

Изображения — файлы PNG или JPEG, ссылки на которые задаются относительно `resources/docs`. Они подготовлены в удвоенном размере относительно отображаемого. Просмотрщик рисует их в половину пиксельного размера, умноженную на масштаб интерфейса, и уменьшает до доступной ширины. Альтернативный текст показывается как подпись.

Изображение должно находиться в отдельном абзаце. В списках, таблицах и примечаниях показывается только его альтернативный текст. Изображения загружаются, когда становятся видимыми, и освобождаются при открытии другой главы.

---

Для латинских заголовков якоря образуются подобно GitHub: нижний регистр, пробелы заменяются дефисами, пунктуация удаляется. Повторяющийся заголовок получает номер: например, `#signals-1` для второго заголовка «Signals». Встроенный парсер сохраняет регистр кириллицы; для русских глав с тем же числом, порядком и уровнями заголовков окно справки также поддерживает английские якоря оригинала. Примеры ссылок этой главы используют такие английские псевдонимы.
