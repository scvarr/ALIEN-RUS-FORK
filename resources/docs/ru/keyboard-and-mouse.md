# Клавиатура и мышь

Краткий список всех действий мышью и сочетаний клавиш. Сочетания клавиш не работают, пока фокус ввода находится в текстовом поле.

## Мышь

| Действие | Режим навигации | Режим редактирования |
| --- | --- | --- |
| Колёсико мыши | Изменение масштаба | Изменение масштаба |
| Перетаскивание со средней кнопкой мыши | Перемещение вида | Перемещение вида |
| Левая кнопка мыши | Удерживайте для приближения | Применить выбранный инструмент, например выделить, нарисовать или толкнуть |
| Правая кнопка мыши | Удерживайте для отдаления | С инструментом выделения: растянуть прямоугольник выделения. С инструментами линии, кривой и многоугольника: удалить последнюю точку |
| Ctrl и щелчок левой кнопкой | | Добавить объект к выделению или исключить из него |
| Shift при перемещении | | Временно переключаться между перемещением выделенных объектов и целых сетей |

## Общие команды

| Сочетание | Действие |
| --- | --- |
| F1 | Открыть или закрыть документацию |
| F7 | Переключиться между полноэкранным и оконным режимом |
| Space | Запустить или приостановить симуляцию |
| Ctrl+N | Создать симуляцию |
| Ctrl+O | Открыть симуляцию |
| Ctrl+S | Сохранить симуляцию |

## Окна

| Сочетание | Окно |
| --- | --- |
| Alt+1 | Управление временем |
| Alt+2 | Управление пространством |
| Alt+3 | Панель эволюции |
| Alt+4 | Параметры симуляции |
| Alt+5 | Автосохранение |
| Alt+6 | MCP-сервер |
| Alt+7 | Журнал |
| Alt+W | Редактор генома |
| Alt+B | Браузер |

## Редактирование

| Сочетание | Действие |
| --- | --- |
| Alt+E | Включить или выключить режим редактирования |
| Alt+N | Инспектировать выделенные объекты |
| Alt+F | Открыть геномы выделенных организмов в редакторе генома |
| Alt+P | Инспектировать выделенные организмы |
| Esc | Закрыть все окна инспектирования или снять выделение |
| Ctrl+C | Копировать выделенное |
| Ctrl+V | Вставить |
| Del | Удалить выделенное |
| Enter | Завершить линию, кривую или многоугольник |
| Esc | Отменить линию, кривую или многоугольник |

## Вид и инструменты

| Сочетание | Действие |
| --- | --- |
| Alt+O | Информация о клетках |
| Alt+X | Экранные сообщения |
| Alt+U | Показать или скрыть интерфейс пользователя |
| Alt+I | Показать или скрыть симуляцию |
| Alt+C | Консольный режим. В консоли Esc возвращает в интерфейс, а Q завершает работу. |
| Alt+H | Массовые операции |
| Alt+Y | Конвертер изображений |
