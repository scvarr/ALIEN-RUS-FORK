# Словарь терминов

**Функция активации.** Функция, которую нейрон применяет к взвешенной сумме входов, например *Tanh* или *Identity*. См. [Нейросети и сигналы](neural-networks.md#activation-functions).

**Автозапуск.** Настройка сенсоров и конструкторов, позволяющая действовать самостоятельно, без сигнала в канале #0.

**Возврат энергии.** Доля высвобождаемой энергии, возвращающаяся во внешний резервуар. См. [Энергия](energy.md#the-external-energy-pool).

**Базовые параметры.** Параметры симуляции, действующие во всём мире, если слой их не переопределяет.

**Ветвь.** Одна из нескольких копий гена, которые конструктор строит вокруг себя.

**Клетка.** Живой объект: имеет энергию, тип клетки, нейросеть и принадлежит организму с геномом. См. [Как устроена жизнь](how-life-works.md).

**Тип клетки.** Особая способность клетки, например сенсор, мышца или атакующая клетка. См. [Типы клеток](cell-types.md).

**Канал.** Одно из восьми значений сигнала, от #0 до #7.

**Повторение.** Одна из нескольких копий гена, которые конструктор строит последовательно.

**Соединение.** Упругая связь между двумя объектами. Клетки обмениваются по соединениям энергией и сигналами. Объект может иметь до шести соединений.

**Вес соединения.** Степень влияния сигнала соединённой клетки на данную клетку.

**Конструктор.** Дополнительная функциональность клетки, строящая новые клетки по гену. См. [Геномы и построение](genomes.md#how-construction-works).

**Организм.** Сеть клеток, построенных по одному геному.

**Цвет настройки.** Один из десяти цветов, которые может иметь объект. Многие параметры симуляции можно задавать по цветам.

**Цикл.** Ритм работы клеток: каждые 6 шагов времени каждая клетка выполняет свою нейросеть и функцию типа клетки.

**Режим редактирования.** Режим, в котором мышь выбирает, создаёт и изменяет объекты. Переключается сочетанием Alt+E.

**Энергетическая частица.** Свободная энергия, перемещающаяся по миру и поглощаемая клетками.

**Внешний резервуар энергии.** Запас энергии за пределами мира, способный снабжать конструкторы и источники излучения. См. [Энергия](energy.md#the-external-energy-pool).

**Снимок мира.** Снимок мира в памяти с возможностью восстановления, создаваемый в окне «Управление временем».

**Жидкость.** Частицы без соединений, текущие как жидкость.

**Свободная клетка.** Органическое вещество без генома. Пища для организмов.

**Переднее направление.** Направление, которое организм считает передним. Сенсоры, мышцы и коммуникаторы измеряют направления относительно него.

**Ген.** Часть генома, описывающая группу клеток и её форму.

**Геном.** План строения организма, состоящий из генов. См. [Геномы и построение](genomes.md).

**Головная клетка.** Первая клетка организма. Определяет переднее направление и обеспечивает целостность организма.

**Слой.** Область мира, в которой переопределяются некоторые параметры симуляции и может действовать силовое поле. См. [Параметры симуляции](simulation-parameters.md#layers-and-radiation-sources).

**Происхождение.** Группа родственных организмов. Организм основывает новое происхождение, когда накопленные мутации превышают порог.

**MCP.** Model Context Protocol — протокол, через который ИИ-агенты управляют ALIEN. См. [ИИ-агенты](ai-agents.md).

**Нейрон памяти.** Один из четырёх выходов нейросети, сохраняющих значение между циклами и доступных только самой клетке.

**Метамутация.** Случайное изменение вероятностей мутаций, хранящихся в геноме.

**Мутация.** Случайное изменение генома при передаче потомку. См. [Эволюционные эксперименты](evolution.md#ingredient-2-variation).

**Узел.** Описание одной клетки в гене.

**Нормальная энергия.** Опорное количество энергии клетки, по умолчанию 100. Столько стоит построение клетки.

**Объект.** Любая частица вещества: частица твёрдого вещества, жидкость, свободная клетка или клетка.

**Потомок.** Организм, построенный другим организмом.

**Источник излучения.** Место появления энергетических частиц. См. [Энергия](energy.md#radiation-sources).

**Сырая энергия.** Ещё не преобразованная энергия в клетке, полученная при поглощении частиц или атаках. Конвертеры превращают её в доступную энергию.

**Опорное значение.** Значение параметра симуляции на момент её загрузки. Изменённые параметры можно к нему вернуть.

**Корневой ген.** Первый ген генома, описывающий тело организма.

**Семя.** Единственная клетка с конструктором, строящим организм по геному.

**Отделение.** Настройка конструктора, позволяющая завершённой постройке отсоединиться и стать новым организмом.

**Генератор формы.** Настройка гена, размещающая его узлы по шаблону, например в виде отрезка или шестиугольника.

**Сигнал.** Восемь значений, которые клетка выдаёт в каждом цикле, а её соседи читают в следующем.

**Частица.** Частицы твёрдого вещества, соединённые в упругие тела, например камни и стены.

**Статичность.** Свойство объектов, удерживающее их на месте и защищающее от сил и старения.

**Липкость.** Свойство объектов, позволяющее соединяться с другими объектами при контакте.

**Телеметрия.** Входы нейросети, описывающие саму клетку: энергию, атаки, возраст и скорость.

**Шаг времени.** Наименьшая единица времени в симуляции.

**Доступная энергия.** Энергия, поддерживающая жизнь клетки и оплачивающая её действия.

**Донор.** Тип клетки, служащий временным заполнителем и исчезающий после построения.
