# Файлы и командная строка

Эта глава описывает файлы, с которыми работает ALIEN, автоматическое сохранение симуляций, обмен работами через браузер и запуск симуляций без окна.

## Типы файлов

| Файл | Содержимое |
| --- | --- |
| *.sim* | Полная симуляция: все объекты, частицы энергии, организмы и геномы, параметры симуляции, история статистики, шаг времени и положение области просмотра. |
| *.genome* | Отдельный геном, созданный в редакторе генома. |
| *.settings.json* | Набор параметров симуляции, включая слои и источники излучения. Его можно загрузить в любую симуляцию. |
| *.png* | Изображение, созданное через **Симуляция > Сохранить изображение**. |

## Открытие и сохранение

- **Симуляция > Открыть** (Ctrl+O) загружает файл симуляции, а **Симуляция > Сохранить** (Ctrl+S) сохраняет текущую симуляцию.
- **Симуляция > Создать** (Ctrl+N) создаёт пустой мир.
- Геномы открываются и сохраняются на панели инструментов редактора генома.
- Наборы параметров открываются и сохраняются на панели инструментов окна **Параметры симуляции**.
- Если включено **Настройки > Сохранять при выходе**, ALIEN сохраняет текущую симуляцию при закрытии и открывает её при следующем запуске.

## Автосохранение и точки сохранения

Окно **Автосохранение** (Alt+5) защищает результаты долгих запусков. Оно регулярно создаёт точки сохранения работающей симуляции:

- **Интервал автосохранения (мин)** задаёт время между двумя точками сохранения в минутах.
- **Число файлов** ограничивает число хранимых точек сохранения. Самые старые удаляются.
- **Папка** задаёт место хранения точек сохранения.
- Кнопки позволяют создать точку сохранения вручную или удалить точки. Кнопка загрузки в строке загружает эту точку сохранения.

## Обмен через браузер

Браузер (Alt+B) соединяет ALIEN с сервером ALIEN, где пользователи делятся симуляциями и геномами.

- **Просмотр** работает без учётной записи. Рабочая область **Избранное** содержит симуляции проекта ALIEN, **Сообщество** — всё, чем поделились пользователи.
- **Вход.** Выберите **Сеть > Войти в учётную запись** (Alt+L) или нажмите плашку учётной записи в браузере. Там же можно создать новую учётную запись. С ней вы получаете рабочую область **Личное**, можете публиковать свои работы и реагировать на чужие.
- **Публикация.** **Сеть > Загрузить симуляцию на сервер** (Alt+D) отправляет текущую симуляцию, **Сеть > Загрузить геном на сервер** (Alt+Q) — геном из редактора генома. Вы выбираете имя, описание и доступность: для сообщества или только для себя. Косая черта в имени создаёт папки, например *Мои миры/Океан*.
- **Управление.** Панель браузера позволяет переименовать ваши публикации, заменить их новой версией, переключить доступ между личным и общим и удалить их.
- **Реакции.** Нажмите поле реакций симуляции, чтобы поставить реакцию. Галерея позволяет сортировать по реакциям, дате или загрузкам.

## Интерфейс командной строки

В ALIEN входит вторая программа, *alien-cli* (*alien-cli.exe* в Windows), которая выполняет симуляцию без окон. Она полезна для долгих экспериментов, автоматизации и компьютеров без монитора, например арендованных облачных видеокарт.

```
alien-cli -i input.sim -o output.sim -t 100000
```

| Параметр | Значение |
| --- | --- |
| -i | Файл симуляции для запуска. |
| -o | Файл для записи результата. |
| -t | Количество вычисляемых шагов времени. Без него симуляция работает до нажатия Q или Ctrl+C, при котором также записывается выходной файл. |
| -u, -p | Имя пользователя и пароль сервера ALIEN. |
| --upload-name, --upload-interval | Периодически загружать работающую симуляцию в вашу личную рабочую область под заданным именем с добавленным номером, с указанным интервалом в минутах. |
| -d | Режим отладки: работает медленнее, но записывает подробные файлы времени выполнения и трассировки. |
| --plain | Простой текстовый вывод без цветов и панели состояния. |

Образ Docker с интерфейсом командной строки публикуется как *chrxh/alien:nightly*; подробности см. в README проекта.

**Консольный режим** графической программы (Alt+C) даёт похожие возможности без окончательного выхода из интерфейса, см. [Пользовательский интерфейс](user-interface.md#console-mode).

## Файлы журнала

ALIEN записывает сообщения в *log.txt* в своей папке. Окно **Журнал** (Alt+7) показывает те же сообщения. Если ALIEN аварийно завершается, включите **Настройки > Режим отладки**, воспроизведите проблему и приложите *log.txt* и файл трассировки к сообщению об ошибке, см. [Устранение неполадок](troubleshooting.md).
