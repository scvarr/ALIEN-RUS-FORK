# Геномы и построение

Геном — план строения организма. Эта глава объясняет его структуру, все настройки и то, как конструкторы превращают его в клетки. Она также подробно описывает редактор генома. Для практического знакомства начните с главы [Ваш первый организм](first-creature.md).

## Структура генома

В геноме три уровня:

| Уровень | Содержимое |
| --- | --- |
| **Геном** | Название, угол направления вперёд, вероятности мутаций и список генов. |
| **Ген** | Форма построения, длина соединений, жёсткость и список узлов. |
| **Узел** | Всё об одной клетке: угол, цвет, тип клетки с его свойствами, нейросеть и, при необходимости, конструктор. |

Первый ген, ген 0, — **корневой ген**. Он описывает тело организма. Остальные гены строятся конструкторами и становятся конечностями, органами или украшениями того же организма либо новыми организмами, если у конструктора включено **Отделение**.

![Геном состоит из генов, а гены — из узлов. Конструкторы ссылаются на гены, которые они строят.](../images/genome-structure.png)

## Редактор генома

Откройте редактор через **Редактор > Редактор генома** (Alt+W). У каждого открытого генома своя вкладка. Кнопка **+** в конце панели вкладок создаёт новый геном. В редакторе три столбца:

- **Левый столбец.** Свойства генома, активные вероятности мутаций и список **Структура**. Список показывает все гены и их узлы. Для каждого гена показаны используемые цвета, число узлов и форма, гены, на которые он ссылается, и гены, ссылающиеся на него. Для каждого узла показаны цвет, тип клетки и строящийся им ген. Гены, недостижимые из корневого гена, подсвечены, потому что они никогда не строятся. Кнопки под списком добавляют гены и узлы, удаляют выбранный элемент и перемещают его вверх или вниз.
- **Средний столбец.** Свойства выбранного гена или узла, включая нейросеть узла.
- **Правый столбец.** Работающий **предпросмотр** организма. Он моделирует построение в небольшом отдельном мире. Кнопки предпросмотра включают подробную симуляцию с сигналами и мышцами и показывают редактор нейронной активности, в котором можно задавать значения сигналов и наблюдать реакцию организма.

Панель инструментов вверху предлагает:

| Кнопка | Действие |
| --- | --- |
| Открыть геном, Сохранить геном | Загрузить и сохранить файлы геномов (*.genome*). |
| Поделиться геномом | Загрузить геном на сервер, чтобы он появился в браузере. |
| Клонировать геном | Открыть копию текущего генома в новой вкладке. |
| Копировать геном, Вставить геном | Обмениваться геномами через буфер обмена. |
| Закрыть другие вкладки | Закрыть все вкладки, кроме текущей. |
| Создать точку сохранения, Вернуться к точке сохранения | Запомнить текущее состояние генома и позднее вернуться к нему. |
| Изменить цвета | Заменить один цвет другим во всех узлах. |
| Внедрить геном | Заменить геном выделенных организмов в симуляции текущим геномом. |
| Создать семя | Поместить семя с этим геномом в середину вида. Ему нужна энергия для построения организма. |
| Создать семя с энергией | Поместить семя, которое построит свой первый организм без затрат энергии. |

> **Совет:** Чтобы отредактировать геном существующего организма, выделите одну из его клеток в режиме редактирования и нажмите **Alt+F**. Геном откроется в новой вкладке. После редактирования выделите организмы и используйте **Внедрить геном** либо создайте новые семена.

## Свойства генома

| Свойство | Значение |
| --- | --- |
| Название генома | Название генома. Каждый построенный по нему организм наследует это название. |
| Направление вперёд | Задаёт переднее направление организма как угол между первым соединением головной клетки и направлением вперёд. Новые геномы в редакторе начинают с -180 градусов: переднее направление указывает в сторону от остального тела. |
| Защита от инъекций | Инжекторы других организмов не могут захватить клетки этого организма. |
| Применять метамутации | Вероятности мутаций этого генома сами подвергаются мутациям; см. [Эволюционные эксперименты](evolution.md#letting-evolution-choose-the-rates). |
| Вероятности мутаций | Вероятности и силы всех мутаций. Кнопка **Изменить** открывает полный список. |

## Свойства гена

| Свойство | Значение |
| --- | --- |
| Название гена | Название, отображаемое только в списке структуры. |
| Форма построения | Определяет углы и дополнительные соединения, с которыми собираются узлы. См. ниже. |
| Длина соединений | Расстояние между двумя клетками, построенными одна за другой, от 0.5 до 1.5. Большие значения увеличивают размер организма. |
| Жёсткость | Сила сопротивления клеток деформации их соединений, от 0.05 до 1. При низких значениях тела получаются мягкими и колеблющимися. |
| Единый тип клеток | Каждая клетка этого гена использует тип клетки и свойства типа первого узла. Цвета, углы, нейросети и конструкторы остаются индивидуальными для каждого узла. |

### Формы

Генератор формы располагает узлы гена в геометрический узор. Он также добавляет соединения между клетками, соседствующими в узоре, благодаря чему форма становится устойчивой.

![Восемь форм построения на основе генов с базовыми клетками](../images/shapes.png)

| Форма | Описание |
| --- | --- |
| Отрезок | Линия клеток. Своим углом можно изгибать только первый и последний узлы. |
| Треугольник | Заполненный треугольник, растущий сторона за стороной. |
| Прямоугольник | Заполненный квадрат, растущий кольцо за кольцом. 4, 9, 16 или 25 узлов дают полные квадраты. |
| Шестиугольник | Заполненный шестиугольник, растущий кольцами вокруг центра. 7, 19 или 37 узлов дают полные шестиугольники. |
| Трубка | Полоса клеток шириной в две клетки. |
| Большой леденец | Шестиугольная головка из 19 клеток, за которой следует тонкий хвост из всех последующих узлов. |
| Малый леденец | Небольшая головка, за которой следует тонкий хвост. |
| Зигзаг | Толстая линия, попеременно меняющая направление туда и обратно. |

На изображении выше показаны формы с 12, 16, 16, 19, 20, 27, 19 и 16 узлами.

## Свойства узла

| Свойство | Значение |
| --- | --- |
| Угол | Угол этой клетки относительно соединения с предыдущей клеткой. Учитывается только у первого и последнего узлов гена. У внутренних узлов угол определяется формой. |
| Цвет | Цвет клетки. Многие параметры симуляции задаются отдельно для каждого цвета. |

| Построение | Ген, который эта клетка строит как конструктор, либо *Нет*. При выборе гена появляются свойства построения. |
| Нейросеть | Веса, смещения и функции активации нейросети клетки; см. [Нейросети и сигналы](neural-networks.md). |

## Как происходит построение

Конструктор строит клетки своего гена одну за другой, по одной клетке на каждый запуск:

1. Первая клетка новой ветви размещается рядом с конструктором в направлении, заданном **Углом построения**. Угол отсчитывается от середины наибольшего промежутка между существующими соединениями клетки-конструктора.
2. Каждая следующая клетка вставляется между конструктором и ранее построенной клеткой. Таким образом, цепочка растёт у конструктора, и **первый узел оказывается дальше всего**, а последний — рядом с конструктором.
3. Генератор формы добавляет соединения между новой клеткой и её соседями в узоре.
4. Пока идёт построение, все его клетки находятся в состоянии *Строится* и неактивны.
5. Когда построен последний узел, клетки активируются. При включённом **Отделении** последняя клетка не соединяется с конструктором, поэтому результат отделяется и становится новым организмом.

![Конструктор строит клетки гена одну за другой. Первый узел оказывается дальше всего.](../images/cell-constructor.png)

Поскольку по умолчанию каждая клетка копирует сигнал своего первого соединения, а первое соединение узла *i* направлено к узлу *i+1*, сигналы идут от последнего узла к узлу 0. Размещайте сенсоры в конце гена, а действующие клетки — перед ними.

### Свойства конструктора

| Свойство | Значение |
| --- | --- |
| Интервал автозапуска | Конструктор пытается построить следующую клетку каждые n шагов времени. Фаза различается у разных организмов, поэтому они не строят синхронно. Если значение не задано, конструктор запускается через канал #0. |
| Угол построения | Направление первой клетки; см. выше. Используется только для первой клетки первого повторения в первой ветви. |
| Обеспечение энергией | См. [Энергия для построения](#energy-for-construction). |
| Отделение | Готовая конструкция отделяется и становится новым организмом. |
| Число ветвей | Сколько копий гена конструктор строит вокруг себя, до 6. Только без отделения. |
| Повторения | Сколько раз подряд строится ген; каждая копия прикрепляется к концу предыдущей. Выберите бесконечность для структур, растущих без конца. |

Выходной канал #4 клетки-конструктора сообщает 1, когда клетка построена, и 0, когда попытка не удалась.

### Энергия для построения

Каждая новая клетка стоит **нормальную энергию** цвета конструктора, по умолчанию 100. Конструктор сначала расходует свою **зарезервированную энергию**, затем — доступную. Он строит, только если у него самого остаётся как минимум нормальная энергия. Клетки организма, которым энергия не нужна, передают избыток соединённым клеткам, выполняющим построение, поэтому помогает весь организм.

Настройка **Обеспечение энергией** определяет, насколько далеко распространяется эта поддержка:

- **Только создаваемые клетки.** Конструктор оплачивает только клетку, которую строит.
- **Включая последующие клетки.** Когда конструктор строит клетку, которая сама содержит конструктор, он дополнительно передаёт ей зарезервированную энергию на все клетки гена, который будет строить новый конструктор. Если тот также использует *Включая последующие клетки*, резерв охватывает всё, что достижимо из него. Так организм можно с самого начала обеспечить энергией для построения конечностей. Это не относится к конструкторам, строящим корневой ген.
- **Free.** Полностью без затрат энергии. Этот вариант нельзя задать в геноме. Его используют семена, созданные командой **Создать семя с энергией**; после первого завершённого потомка он сменяется на *Только создаваемые клетки*.

Если конструктору не хватает энергии, а параметр **Передача энергии конструкторам** больше нуля, он запрашивает энергию из внешнего запаса; см. [Энергия](energy.md#the-external-energy-pool).

## Головная клетка и переднее направление

Когда конструктор создаёт новый организм, клетка узла 0 становится **головной клеткой**. Она определяет **переднее направление** организма: угол направления вперёд из генома отсчитывается от первого соединения головной клетки. От головной клетки переднее направление регулярно передаётся всем остальным клеткам организма. Сенсоры, мышцы и коммуникаторы используют его как систему отсчёта.

Головная клетка также поддерживает целостность организма. Клетки, потерявшие связь с ней, например из-за разрыва организма на части, больше не получают эти обновления и через некоторое время начинают погибать.

## Семена

**Семя** — это одна клетка с конструктором, который строит корневой ген с отделением. Редактор генома создаёт семена командами **Создать семя** и **Создать семя с энергией**. Семени, созданному без энергии, прежде чем что-либо построить, нужна энергия из внешнего запаса или окружения.

## Правила допустимых геномов

Редактор генома и симуляция поддерживают корректность геномов:

- Первый и последний узлы гена не могут быть донорами, а клетки-доноры не могут содержать конструктор.
- Конструкторы могут ссылаться на любой ген. Цикл через корневой ген — обычный случай размножения. Цикл, не проходящий через корневой ген, означает неограниченный рост внутри одного организма. Такие циклы разрешены в проектируемых геномах, что полезно для фрактальных структур, но при мутации генома они удаляются.
- При мутации генома с отделением могут строиться не более двух разных генов, а узлы, которые оказались бы отсоединены от остальной части своего гена, превращаются в узлы-доноры.
