# Песочница и редактирование

ALIEN — это ещё и площадка для физических экспериментов. Здесь можно рисовать камни и жидкости, строить конструкции, разрезать их, бросать друг в друга и наблюдать за результатом. Эта глава знакомит с материалами мира и инструментами редактирования. Знания об организмах не требуются.

![Игра с веществом: частицы, жидкости и энергия в движении](../images/sandbox.jpg)

## Материалы

Всё в мире состоит из маленьких круглых частиц, называемых **объектами**. Есть четыре вида объектов, а также свободная энергия:

| Материал | Описание |
| --- | --- |
| **Частица** | Частицы, которые соединяются друг с другом и образуют упругие тела: камни, стены или механизмы. При слишком большой силе соединения разрываются. Частицы заслоняют обзор клеткам-сенсорам. |
| **Жидкость** | Частицы без соединений, текущие подобно жидкости или газу. Жидкости могут светиться. |
| **Свободная клетка** | Органическое вещество без генома. Свободные клетки служат пищей организмам и распадаются при слишком низкой энергии. |
| **Клетка** | Строительный элемент организма. У клеток есть геном, небольшая нейросеть и тип клетки. Их не рисуют вручную: они вырастают из семян, см. [Ваш первый организм](first-creature.md). |
| **Частица энергии** | Свободная энергия, перемещающаяся по миру. Клетки поглощают частицы энергии при соприкосновении. |

У каждого объекта есть несколько основных свойств:

- **Цвет.** Один из десяти цветов оформления. Многие параметры симуляции можно задавать отдельно для каждого цвета, поэтому цвет — не только украшение. Например, частицу цвета 3 можно сделать более хрупкой, чем частицу цвета 4.
- **Энергия.** Энергия объекта также определяет его яркость.
- **Жёсткость.** Насколько сильно объект сопротивляется деформации своих соединений.
- **Статический.** Неподвижные объекты остаются на месте, не подвержены действию сил и не стареют. Используйте их для стен и опор.
- **Липкий.** Липкие объекты образуют новые соединения при соприкосновении с другими объектами.

## Переход в режим редактирования

Нажмите **Alt+E** или круглую кнопку в левом нижнем углу. Рядом с кнопкой появится панель инструментов. У большинства инструментов над панелью отображается небольшая карточка с параметрами и подсказкой по использованию. Снова нажмите **Alt+E**, чтобы вернуться в режим навигации.

## Создание вещества

Выберите на панели один из инструментов создания:

| Инструмент | Использование |
| --- | --- |
| **Рисование от руки** | Удерживайте левую кнопку мыши и рисуйте. Радиус кисти задаёт ширину штриха. |
| **Один объект** | Щёлкните левой кнопкой, чтобы разместить один объект или частицу энергии. |
| **Прямоугольная сеть объектов** | Щёлкните левой кнопкой, чтобы разместить прямоугольник из соединённых объектов. |
| **Шестиугольная сеть объектов** | Щёлкните левой кнопкой, чтобы разместить шестиугольник из слоёв вокруг центра. |
| **Сеть объектов в форме диска** | Щёлкните левой кнопкой, чтобы разместить диск. Внутренний радиус больше 0 создаёт кольцо. |
| **Сеть объектов вдоль отрезка** | Левая кнопка добавляет точки, правая удаляет последнюю точку, **Enter** завершает, **Esc** отменяет создание. |
| **Сеть объектов вдоль кривой Безье** | Как для линии, но точки задают плавную кривую. |
| **Многоугольная сеть объектов** | Как для линии, но точки задают контур заполненного многоугольника. |

В карточке каждого инструмента задаются **цвет**, **материал**, **энергия**, **расстояние** между соседними объектами и жёсткость, а также **Липкий** и **Статический**. У жидкостей дополнительно есть значение **свечения**. При материале *Частицы энергии* инструменты создают свободную энергию вместо вещества.

> **Совет:** **Конвертер изображений** (Alt+Y или кнопка **Узор из изображения**) превращает файл изображения в узор из частиц. Светлые пиксели становятся объектами ближайшего цвета оформления. Это быстрый способ перенести в мир логотип или рисунок.

## Выделение и перемещение

С инструментом **Выделение и перемещение**:

- **Щёлкните** объект, чтобы выделить его. Удерживайте **Ctrl** при щелчке, чтобы добавлять объекты в выделение или исключать их.
- **Тяните с зажатой правой кнопкой мыши**, чтобы выделить все объекты внутри прямоугольника.
- **Тяните с зажатой левой кнопкой мыши**, чтобы переместить выделение. Если симуляция работает, выделение следует за мышью и сохраняет импульс после отпускания кнопки: так можно бросать предметы.
- **Перетаскивайте круглый маркер** над рамкой выделения, чтобы повернуть его.
- Нажмите **Esc**, чтобы снять выделение.

Две кнопки панели определяют область действия перемещения. **Применять к выделенным объектам** перемещает только выделенные объекты, поэтому их соединения с невыделенными могут разорваться. **Применять ко всей сети** перемещает сети целиком, если в них входят выделенные объекты. Удерживание **Shift** временно переключает эти варианты. **Соединять при касании** соединяет перемещаемые объекты со всем, чего они касаются.

## Панель действий выделения

Над каждым выделением располагается небольшая панель действий:

- **Цвет**, **Липкость** и **Статический** меняют эти свойства у всех выделенных объектов.
- **Выровнять скорости** задаёт всем выделенным объектам одинаковую скорость, чтобы они двигались единым блоком.
- **Снять напряжения** принимает текущие расстояния соединений за их длины покоя, убирая напряжение.
- **Соединить соседние объекты внутри выделения** соединяет соседние выделенные объекты.
- **Размножить** создаёт копии выделения по сетке или в случайных местах по всему миру.
- **Копировать** (Ctrl+C) и **Удалить** (Del). **Вставить** (Ctrl+V) помещает копию в центр области просмотра и выделяет её, чтобы можно было перетащить её на нужное место.
- **Исследовать** открывает окна исследования выделенных объектов, геномов или организмов.
- **Преобразование** позволяет численно задать положение, скорость, угол поворота и угловую скорость.

## Разрезание и толкание

- **Ножницы.** Удерживайте левую кнопку мыши и проводите через соединения, чтобы разрезать их. С опцией **Только в выделении** разрезаются только соединения между выделенными объектами.
- **Приложить силу.** Удерживайте левую кнопку мыши и тяните, чтобы толкать всё под курсором в направлении движения. Инструмент доступен во время работы симуляции.

## Исследование и изменение отдельных объектов

Выделите один или несколько объектов и нажмите **Alt+N** либо выберите **Исследовать** на панели действий. Для каждого объекта откроется окно исследования (до 20 одновременно). Оно показывает все свойства и позволяет менять их: положение, скорость, энергию, цвет, неподвижность и липкость, соединения, а у клеток — тип клетки, нейросеть и многое другое. **Esc** закрывает все окна исследования.

## Массовые операции

**Инструменты > Массовые операции** (Alt+H) меняет множество объектов одновременно. Операции задают случайные значения в указанных диапазонах: цвета клеток и геномов, энергию, возраст, отсчёт до взрыва детонаторов, идентификаторы происхождения, свечение жидкостей и вероятности мутаций геномов. С опцией **Только выделение** меняются только выделенные объекты. Это удобно для создания разнообразия, например разных оттенков большого камня или разных цветов в популяции.

## Физика вкратце

Несколько параметров симуляции определяют поведение вещества. Они находятся в окне **Параметры симуляции** (Alt+4); подробности см. в главе [Параметры симуляции](simulation-parameters.md):

- **Трение** замедляет любое движение. Без трения предметы продолжают двигаться бесконечно.
- **Максимальная сила** определяет, когда разрываются соединения. Низкие значения делают конструкции из частиц хрупкими.
- **Жёсткость связанных частиц** заставляет соединённые частицы двигаться более подобно твёрдому телу.
- **Давление**, **Вязкость** и **Длина сглаживания** управляют поведением жидкостей.
- По умолчанию гравитации нет. **Слой** с линейным силовым полем добавляет гравитацию, ветер или течения во всём мире или в его части.

> **Совет:** Перед экспериментом создайте снимок мира (окно **Управление временем**). **Загрузить снимок мира** возвращает предыдущее состояние, позволяя повторять опыты сколько угодно.
