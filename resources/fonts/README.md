# Noto text fonts

Unmodified static fonts from https://github.com/notofonts/noto-fonts at commit `ffebf8c1ee449e544955a7e813c54f9b73848eac`.

SIL Open Font License 1.1; copyright and license are included in `OFL.txt`.

Original paths:
- `hinted/ttf/NotoSans/NotoSans-Regular.ttf`
- `hinted/ttf/NotoSans/NotoSans-Bold.ttf`
- `hinted/ttf/NotoSansMono/NotoSansMono-Regular.ttf`
- `LICENSE`

Regular and bold Noto Sans cover GUI text; Noto Sans Mono covers monospace text.
Existing FontAwesome, AlienIconFont and Reef assets are retained.
